# CTFd Themes

A set of themes created by DUCA for CTFd.

## Themes

| Theme | Path | Description |
| --- | --- | --- |
| Halloween | [`themes/halloween`](themes/halloween) | Spooky pumpkin and purple dark theme |
| Christmas | [`themes/christmas`](themes/christmas) | Festive red, gold and pine green dark theme |
| Summer | [`themes/summer`](themes/summer) | Sunny night-beach dark theme with orange and turquoise |
| Cyberpunk | [`themes/cyberpunk`](themes/cyberpunk) | Neon pink, cyan and yellow on violet-black, with scanlines |
| Haxxor | [`themes/haxxor`](themes/haxxor) | Hacker-terminal theme in matrix green on black |

Each theme is a drop-in CTFd theme directory: copy it to `CTFd/themes/<name>` and select it in the admin panel.

## Compatibility

All themes in this repository target the **CTFd 3.8** series and have been tested with **CTFd 3.8.9** (Docker image `ctfd/ctfd:3.8.9`, user mode `teams`). They are built on the CTFd 3.8 core theme (the prebuilt `static/assets` bundle). Other 3.8.x releases should work but are untested. CTFd 3.7 and older, and 3.9 or newer, are untested and may break because the core JS bundles and templates change between releases.
